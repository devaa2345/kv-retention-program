# M2 question-aware pointer result

The preregistered lexical pointer **did not beat floor** on a new independent
64-instance, 256-query real-text test. It greatly improved gold-sentence
selection, but the literal mask still often copied the wrong substring from
the correct sentence, especially on SQuAD. No M3 or RTX Pro 5000 run occurred.

Protocol: `PREREG_REALTEXT_POINTER_M2.md`; held-out indices 136–199, manifest
SHA-256 `2f9c4b1aad0dd6d1a29ae9941a204bbe12a6a3b791c2e3cb27afc32b93bd588a`.
The lexical pointer and n=64 were committed before held-out generation.
All four arms used the same A1 prompt, 0.2802 retained-context ratio and strict
whole-answer exact match after casefold and whitespace-run normalization only.
Both masked arms used `literal_v1`, which emits only exact substrings of the
selected sentence. The two masked SnapKV arms matched unmasked SnapKV on
keep-set hash, budget, context length and held status for all 256 queries.
All 256 queries completed in every arm. The corrected full-context invented
check found zero invented masked answers.

| Arm | Correct /256 | Accuracy | Invented | Cap stops |
|---|---:|---:|---:|---:|
| floor_pos | 74 | 0.2891 | 145 | 1 |
| SnapKV | 52 | 0.2031 | 147 | 3 |
| SnapKV + attention pointer + literal mask | 61 | 0.2383 | 0 | 3 |
| SnapKV + lexical pointer + literal mask | 71 | 0.2773 | 0 | 1 |

All intervals are 95% paired bootstraps over complete four-query instances,
10,000 resamples, seed 5070. Each query changes accuracy by 1/256 = 0.3906
percentage points.

| Contrast | Difference | 95% CI | Converted / broken |
|---|---:|---:|---:|
| **Lexical masked SnapKV − floor_pos (primary)** | **−0.0117** | **[−0.0781, +0.0508]** | **28 / 31** |
| Lexical masked SnapKV − own unmasked SnapKV | +0.0742 | [+0.0273, +0.1172] | 27 / 8 |
| Attention masked SnapKV − own unmasked SnapKV | +0.0352 | [−0.0039, +0.0742] | 18 / 9 |
| Lexical masked SnapKV − attention masked SnapKV | +0.0391 | [+0.0117, +0.0703] | 13 / 3 |

SnapKV retained the gold sentence in 176/256 queries and was wrong on 129 of
those. The old attention pointer selected the gold sentence in 112/256;
the lexical pointer did so in 162/256, a +0.1953 hit-rate improvement
with paired instance CI [+0.1406, +0.2500]. This is a genuine pointer gain.
Yet lexical masking answered only 71/162 gold-selected queries correctly:
the remaining 91 copied a wrong substring even from the correct sentence.
The pointer-only explanation is therefore insufficient for beating floor.

| Question type (128 each) | floor_pos | SnapKV | attention mask | lexical mask | Lexical mask − floor, 95% CI |
|---|---:|---:|---:|---:|---:|
| SQuAD | 28 | 20 | 16 | 18 | −0.0781 [−0.1484, −0.0078] |
| Natural-filler code needles | 46 | 32 | 45 | 53 | +0.0547 [−0.0469, +0.1484] |

On SQuAD, the lexical pointer selected the gold sentence in 68/128, but the
mask returned the exact gold answer in only 18 of those 68. Examples of wrong
copies from a correct sentence include `young` for `the young and the elderly`,
`1850` for `1830`, and `Edict of Nantes` for `Edict of Fontainebleau`. These
are answer-extraction failures, not sentence-localization failures. On needles,
the lexical pointer selected the gold sentence in 94/128, and 53 were answered
correctly. The SQuAD regression against floor is decisive for the mixed-set
claim; a needle-only benefit remains unconfirmed by its interval.

Development prefill captures took 0.62 minutes (24 old pilot instances) and
0.76 minutes (32 fresh development instances) of GPU processing after model
load. Development generation took 1.66 minutes; the 64-instance confirmatory
generation took **3.35 GPU processing minutes after load**. No further
generation or prompt iteration was performed after seeing this held-out result.
The raw confirmatory rows are `out/realtext_pointer_M2_heldout_results.jsonl`.

## Post-hoc audit of correct-sentence, wrong-answer copies

After the confirmatory score was locked, all **91** lexical-mask failures with
the gold sentence selected were classified by comparing the exact emitted and
gold character intervals in that sentence. This audit explains errors; it is
not a new test or a basis for tuning on these 64 instances. Its per-query rows
are `out/realtext_pointer_91_failure_audit.jsonl`, generated by
`out/_realtext_pointer_failure_audit.py`.

| Failure category | SQuAD | Needles | Total |
|---|---:|---:|---:|
| Different, nonoverlapping span | 28 | 3 | **31** |
| Copy starts inside gold or clips its boundary | 9 | 21 | **30** |
| Correct start, EOS before full gold | 8 | 12 | **20** |
| Copy includes gold plus extra prefix | 2 | 2 | **4** |
| Copy partly overlaps gold | 2 | 3 | **5** |
| Correct start, copies beyond gold | 1 | 0 | **1** |
| Empty output | 0 | 0 | **0** |

Thus 60/91 are boundary or overlap errors and 31/91 are wholly wrong spans.
For needles, 38/41 failures overlap the right code; the mask permits an EOS
after a partial code or a start in the middle of it. For SQuAD, 28/50 failures
copy a different span from the correct sentence, so fixing EOS alone cannot
solve ordinary prose QA. A separate "started right then drifted" category is
structurally impossible for a literal contiguous-substring mask: two copies
starting at the same character in the same sentence cannot diverge before
one ends. The next design should test both answer-start selection and
answer-boundary control on fresh development data. An eight-digit rule for
the needle template can be an answer-type diagnostic, but cannot support a
general real-text QA claim.
